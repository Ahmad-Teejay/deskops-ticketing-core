# LogicVeda Ticketing System

DeskOps ticketing project for LogicVeda Phase 1.

## Status

Walking skeleton in progress. The backend health endpoint runs locally and through Docker Compose. CI, authentication, and tenant middleware are still to be added.

## Stack

- Node.js 22
- TypeScript
- Express
- Docker and Docker Compose

## Run the backend locally

```bash
cd backend
npm ci
npm run dev
